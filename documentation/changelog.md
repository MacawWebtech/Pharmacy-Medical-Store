# Changelog

## 1.1.0 - 2026-11-16

Modern design refresh.

- New fonts: Plus Jakarta Sans and Inter
- Floating glass header, gradient hero with floating info chips and stats, trust strip
- Bento-style Health Essentials grid, connected steps, dark glass "Why choose us" section
- Pill buttons, larger rounded cards, rounded banners and footer
- Gentle scroll-reveal animations (off for reduced-motion and on phones)
- Dark mode updated for the new look

## 1.0.0 - 2026-11-16

First release.

- Seven pages: Home, Products, Home Delivery, Contact, About Us, 404, Coming Soon
- Light and dark mode with system preference detection
- RTL support with direction toggle
- Products page with search, sort, category tabs, skeleton loaders and Load more
- Prescription enquiry form with client-side validation, Formspree and Netlify support
- Placeholders for Mailchimp / ConvertKit, Google Maps, Stripe / PayPal and booking
- SEO files: sitemap.xml, robots.txt, JSON-LD, Open Graph tags
- Documentation set
